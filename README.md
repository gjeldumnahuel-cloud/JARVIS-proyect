# J.A.R.V.I.S.

Asistente personal de escritorio para Windows, desarrollado con Electron.

## Descarga

Descarga la última versión desde [Releases](https://github.com/gjeldumnahuel-cloud/JARVIS-proyect/releases).

## Actualizaciones

La aplicación comprueba si hay actualizaciones al iniciar y las instala al cerrarse.

## Importante

No publiques archivos de configuración ni credenciales. Para reportar problemas, usa la sección **Issues**.
